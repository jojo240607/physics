# 超越商用引擎路线图 (Beyond-Commercial Roadmap)

> 目标:不只是"媲美商用",而是在商用引擎的共性弱点上建立**代差级**优势。
> 基线状态见 PLAN.md / PLAN_NEXT.md(D1–D4, M1–M27, S1–S8, L1–L4, G1, C1 全绿)。

---

## 一、商用引擎(PhysX / Havok / Rapier / Jolt / Box2D)的共性弱点

这些是我们可以差异化"超越"的切入点,而非与它们正面拼单场性能:

| 弱点 | 商用现状 | 我们的现状 | 超越机会 |
|------|----------|-----------|----------|
| **多物理场统一** | 刚体/流体/布料各自独立引擎,耦合靠手动胶水代码,光学几乎没有 | 已有 `World<Subsystem>` + `couple_*()` 双向耦合(刚↔流↔软↔热↔光) | **架构代差**:一个世界同步演化所有场,自动双向耦合 |
| **确定性** | PhysX 多线程不保证逐位复现;回放靠重放输入且依赖平台 | S8 已有逐位回放 + 校验和 | **锁帧同步/反作弊/影视可复现**硬门槛 |
| **多精度** | 基本锁死 f32 | `RealField` f32/f64 同接口 | 科研级精度 + 游戏级速度按需切换 |
| **可组合性** | 插件扩展困难,新增物理场需大改内核 | 插件式 `Subsystem`,任意加新场 | 用户可自定义新物理场 |
| **光学集成** | 无(渲染层另做) | 已有完整折/反射/焦散 + GPU | 物理驱动的真实光影 |

=> 我们的**核心差异化 = "统一多物理场确定性引擎"**。商用引擎是"多个单场工具箱",我们是"一个耦合世界"。

## 二、超越路线(分阶段)

### 阶段 A:把架构代差变成"可信证据"(最高杠杆,先干这个)
- **A1 统一耦合闭环 demo**:刚体落进 SPH 流体 + 软体布帘被风(流体)吹动 + 焦散实时投影到布帘。一个 `World` 跑所有场,出可量化对比视频/数据。
- **A2 确定性交叉验证**:S8 回放扩展到"多场混合世界",证明多场耦合下仍逐位可复现(商用做不到)。
- **A3 多精度一致性**:同一场景 f32 vs f64 结果差异 bounded 且有报告。

### 阶段 B:规模化 + 多场数值刚性(商用下限是"能跑大场景且稳定")
- **B0 [关键攻关] SPH 入水冲击 / 多场耦合能量守恒**:`coupled_world` demo 实测发现,
  SPH 在刚体入水瞬间能量瞬态暴涨(初始 KE_f≈223 → 入水帧暴涨至 3.5×10⁵,≈1600×),
  之后系统耗散回落稳定(KE_f≈25)。根因:(a) SPH 初始静止晶格粒子间距(0.12)<光滑长度
  h(0.2)导致首步压力发散;(b) `FluidWorld::couple_bodies` 在刚体侵入时把粒子速度强制
  吸附到刚体速度,叠加 WCSPH 半隐式欧拉的"自发沸腾"刚性。这是超越商用必须攻克的科学
  问题——商用引擎(PhysX 流体/FLIP)同样受入水冲击数值刚性困扰,但我们的统一耦合架构
  让问题**可量化、可定位**(一个 World 内逐场能量可审计)。攻关方向:SPH 初始抖动初始化
  (Bluenoise/Jitter)、入水冲击的 CFL 自适应子步、couple_bodies 的能量守恒冲量格式
  (用对称冲量而非单向吸附)。
- **B1 刚体并行/分岛规模化**:islands 已有时,扩展到 10k+ 刚体稳定 60fps。
- **B2 流体 GPU 规模化**:当前 GRAN10k 1.15ms / SPH50k 7ms,目标 SPH 200k+。
- **B3 统一 BVH / 跨场空间索引**:刚/软/光共享一套加速结构。

### 阶段 C:工业级稳定性与工具链(商用入场硬门槛)
- **C1 crates.io 发布**(已有 C1,卡在 `cargo login`)。
- **C2  NaN/爆炸自愈**:`World::step_checked` 已有,扩展到多场 + 自动降级(切 f64 / 降子步)。
- **C3 基准测试套件**:对标 PhysX 标准场景(堆叠/链式/破碎)的量化对比报告。
- **C4 文档与示例**:统一 API 文档 + 跨场 coupling 教程。

### 阶段 D:杀手级差异化(真正"超越"而非"持平")
- **D1 物理驱动焦散实时全局光照**(已具备,做出商用引擎没有的"物理正确光影")。
- **D2 确定性云同步原语**:基于 S8 的 `Replay` + 校验和,提供"百万客户端逐位一致"的同步 API。
- **D3 自定义物理场 SDK**:用户用 `Subsystem` trait 写新场(电磁/声场/人群),无需改内核。

## 三、立即启动(A1)

本轮先交付 **A1 统一耦合闭环 demo** 的可运行示例 + 量化对比:
- 新建 `crates/phy-demo-web/examples/coupled_world.rs`
- 场景:刚体球落入 SPH 水池 → 激起水花推动软体布帘 → 焦散实时打到布帘与地面

- 目标:证明"一个 World 同步演化多场且能量自洽"——这是商用单场工具箱无法表达的能力
